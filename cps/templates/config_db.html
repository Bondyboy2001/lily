If Lily can't open your library
Common causes
  • Calibre or another app is using the same metadata.db while Lily runs
  • The library is on a network share, unionfs or mergerfs without NETWORK_SHARE_MODE enabled in docker-compose
  • The path to metadata.db changed or is wrong
  • metadata.db is missing or corrupted (try opening it in Calibre)
  • Lily lacks permission to read or write the file

If none of these apply, restore metadata.db from a backup or use Last Resort below.
