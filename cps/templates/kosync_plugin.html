Compatible with: KOReader on Android, Kindle, Kobo, and other supported devices

Installation Instructions

  1. Download the plugin file koplugin.zip using the button above.
  2. Extract koplugin.zip to a temporary location. This will create a cwasync.koplugin folder containing all the plugin files.
  3. Move the cwasync.koplugin folder into your device's /koreader/plugins/ directory.

Important: Extract the zip file directly to the /koreader/plugins/ directory. The extraction will automatically create the cwasync.koplugin folder with the correct structure.

Accessing the Plugin

Where to find it: After installation and restarting KOReader, tap the Navigation menu icon () at the top of the screen to open the Navigation menu. Look for "Lily Progress Sync" in the menu list. If you have many plugins installed, you may need to scroll down or check the second page of menu items.

Note: If the plugin doesn't appear after restarting, follow these steps to manually enable it:

  1. Open KOReader on your device.
  2. Tap the top menu area to bring up the navigation bar.
  3. Navigate to: Settings → Tools → Plugin management
  4. Find "Lily Progress Sync" in the plugin list and enable it if it's not already enabled.

Using the Sync Feature

Once configured, the plugin will automatically sync your reading progress in the background.

Your progress will be saved when you:

  • Turn pages
  • Close a book
  • Switch between books
  • Exit KOReader

Note: Make sure you have an internet connection for the sync to work. The plugin will automatically retry failed sync attempts when connectivity is restored.
